# NO LIMITS — магазин спортивного питания

Интернет-магазин на React, TypeScript и Vinext с каталогом, корзиной, заявками и защищённой админ-панелью.

## Публичная версия

https://no-limits-sport-nutrition.isma1911.chatgpt.site/

Админ-панель расположена по адресу `/admin` и защищена авторизацией Supabase.

## Возможности

- каталог товаров из Supabase с резервными встроенными данными;
- фильтры, поиск, сортировка и корзина;
- оформление заявки с проверкой остатков;
- управление товарами, фотографиями, категориями и остатками;
- управление заказами и их статусами;
- автоматическое списание товара при подтверждении и возврат при отмене;
- адаптивный интерфейс для компьютеров и телефонов.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
cp .env.example .env.local
npm run dev
```

Заполните в `.env.local` публичный URL и publishable key своего проекта Supabase. Никогда не добавляйте `service_role`, secret key или пароли в клиентские переменные.

## Настройка базы

Пошаговая инструкция находится в [SUPABASE_SETUP.md](./SUPABASE_SETUP.md). SQL-схема и начальные товары лежат в папке [`supabase`](./supabase).

## Проверка

```bash
npm run build
```
